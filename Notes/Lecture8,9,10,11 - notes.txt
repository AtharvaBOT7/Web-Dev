Forms are a structured way to collect information from the user input.

we use the <form> tag to create forms in html for user input.

then we have <input> tag and we can display this in multiple ways. Whenever we use the input tag, we must specify the type attribute to denote what type of data it is taking as input. Available types are radio, date, text (default), checkbox, submit etc.
**** When we want to access the data from these input fields, we have the id attribute inside the input tag. every id must and must be unique across the webpage. We will also give names to the input tag so that we know which input tag we are referring to, good practice.
*** when we have type="submit", the data present inside the form will be submitted somewhere. Type submit will create a submit button for the entire form.
There are 2 ways to submit the data present in the form to a source, one is the submit tye and other is the action attribute inside the form tag itself which appears by default.

Then we have <label> tag which labels the type of input that field is taking for example password or login information etc. This also appears in screen reader ie when someone tries to read the content available on the sreen. ** Every label tag has a for="" attribute which must be filled and the id of the for attribute must always be equal to the id of the input field so that we know what it matches.
This means label's for and input's id attributes must have the same values. This means even if we click on the actual input type or the label, it will select the option.

We have the placeholder attribute inside the input tag.

For radio buttons, if we have the same name for different radio buttons then we will be able to select only one of the values.

Every id attached to an element must be unique.

We also have a tag called <details>, this tag enables us to have frequently asked questions, like when we tap on the question, answer appears and when we tap again the answer disappears.

If we define this at the top:
<a href="#work">Work Experience</a> <br>

and have this defined in the actual Work Experience section:
<h2 id="work">Work Experience</h2>

****** We always access the id of an element using # symbol and we access the class element using . symbol. ******

Then after clicking the Work Experience button at the top, it will scroll the page down to the actual work experience section on the page.

To add an image, we use the <img> tag.
Adding a loading="lazy" attribute in the image tag means that the browser will load the image only when the image is about to come in the user's viewport and not when the page loads, it increases the page load speed.

We can add an audio file in HTML webpage using the <audio> tag and we have a special attribute inside the audio tag called controls, without defining controls attribute, the audio file will never be visible on the webpage.

Similar is the case with video tag, we will need controls special attribute to play / pause / fast forward the video and audio controls.

iframe: Inline Frame element, it is used to attach external links like webpages / videos on a webpage. Basically used to show an external document on your current webpage.

So when we have external YT link inside an iframe, youtube will refuse to connect, https://www.youtube.com/watch?v=eacDqj2C-IA this is the usual link but inside an iframe we will have to replace watch keyword with embed because we are embedding that video inside our iframe. And other thing is to remove the ?v= part as well. So the link we will input inside our src tag will be https://www.youtube.com/embed/eacDqj2C-IA
