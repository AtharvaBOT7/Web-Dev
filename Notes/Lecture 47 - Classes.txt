GETTERS AND SETTERS:

If we have some private variables inside a class, then we will need getters and setters to access the private variables outside the class scope.
Getter : Used to access the private variable value inside the class from outside the class.
Setter: Used to update the value of the private value from outside the class.




DEFAULT PARAMETERS
If we forget to assign values to some of the parameters, then we can assign some default values.

function sayName(myName = "default name"){   // Setting default parameters
    console.log("My name is: ", myName);
}

if we call sayName() then the output will be default name.
