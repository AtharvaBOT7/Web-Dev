Arrays are non primitive data type, reference types are also called non primitive data types.

Arrays, Object and Functions come under reference type.

We call the ints, bool as primitive data types because they take up specific size. But it is not the case reference types.

In JS, we have 2 types of memories that can be assigned to a program in JS:
- Stack Memory (int, bool, etc)
- Heap (Array, object)

We will always need a reference to access elements in the heap memory and the reference is stored inside stack memory. Actual data is stored inside heap memory and the reference is stored in stack memory. 

Object is a collection of key and value pairs.

When we create an object, for example:
let obj = {
    name: "Atharva",
    "full name": "Atharva Chundurwar",
    weight: 100,
    height: "5ft 11inch",
    age: 23,
    greet: function() {
        console.log("Hello I am Atharva Chundurwar");
    }
}
This will create a variable named ibj inside the stack memory which will be aa pointer and it will point to the memory location of the actual object which is placed inside the heap memory. 

If we later so let obj2 = obj; then this will create a shallow copy of the object, which means that we will allocate memory to the variable named obj2 inside the stack memory and it will point to the same memory location as obj, we will not create a second object inside heap memory. This is shallow copy.

// REDUCE METHOD
If we have a set of complex mathematical calculations and we at the end want a single output value, then we use reduce method.

In reduce method, we have two variables one is accumulator (we can initialize this manually, if not manually initialized, accumulator will take up the value of the first element in the array) and one is current (if we have manually initialized acc, then current will take the value of the first indexed element in the array and if acc is not initlized then acc will take up first element value and current will take up second element value).

Example:
let arr = [10,20,30,40];

let ans = arr.reduce((acc, curr) =>{
    return acc + curr;
}, 0)
// The value zero after the function initialization means that we have manually assigned the value to our accumulator.

console.log(ans);  // Output will be 100, the addition of all the elements inside the array.
